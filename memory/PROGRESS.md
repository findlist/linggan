## 5. 下一轮唯一首选任务

**任务：设计并实现可测试的本地 JSON 持久化接口，为后续 PostgreSQL 迁移保留边界。**

选择理由：M0 已完成，候选目前仍只输出到标准输出；先建立与具体数据库解耦的持久化边界，才能在不提前选择生产数据库配置的情况下继续开发发布状态机、幂等和趋势迁移。

验收条件：

1. 定义候选存储接口，业务调用方不依赖文件系统路径或 PostgreSQL 客户端；
2. 提供本地 JSON 实现，所有读写数据均通过共享 Schema 校验，并保留未来替换数据库适配器的边界；
3. 同一候选重复写入不会产生重复记录，写入失败不会留下部分 JSON；
4. 自动测试至少覆盖首次写入、重复写入、空存储和无效存储数据；
5. `npm run validate:data`、`npm test`、`npm run typecheck`、`npm run pipeline:daily` 和 `npm run build` 全部通过；
6. 更新本文件，将已完成任务移出当前首选。
