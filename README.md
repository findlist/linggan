# 灵感 Linggan

面向 AI 视频创作者的创意生产工作台：将热点、原创角色原型、场景和叙事结构组合成可以立即制作的视频方案。

## 当前 MVP

- 今日灵感流：展示经过可视化与生成难度筛选的方案
- 创意组合器：角色原型 × 场景 × 叙事味道
- 方案详情：钩子、角色、场景、30 秒结构与风险提示
- 收藏、复制、移动端导航与无障碍交互
- 深色 Aurora 视觉系统，响应 375px—1440px

## 本地启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

生成一份每日候选报告：

```bash
npm run pipeline:daily
```

校验基础知识库、种子数据与正式趋势存储：

```bash
npm run validate:data
```

将 `data/collection-inbox/` 中通过 Schema 的采集批次去重迁移到本地正式趋势库：

```bash
npm run migrate:trends
```

初始化默认 SQLite 数据库和基础知识数据：

```bash
npm run database:init
```

数据库通过 `DATABASE_URL` 配置，默认是 `file:./data/linggan.sqlite`。配置、迁移和重建说明见 [SQLite 数据库说明](database/README.md)。SQLite 文件不提交 Git，原始采集批次会提交并可用于重建数据库。

基础作品、知名人物、人物关系和抽象名场面存放在 `data/knowledge-base.json`。具体知名角色与名场面仅作 `reference_only`，不得作为精确复刻素材。

自进化系统的完整规划见 [开发计划](docs/DEVELOPMENT_PLAN.md) 和 [内容分类规范](docs/CONTENT_SYSTEM.md)。当前脚本只读取示例趋势并向标准输出生成候选，不会自动发布内容。

## 产品路线

1. **验证期**：每日人工审核 10 条创意，记录查看、收藏、复制和成片率。
2. **工具期**：接入模型生成分镜与提示词，加入项目保存、版本记录和导出。
3. **增长期**：热点雷达、个人角色库、系列化创作、创作者模板市场。
4. **商业期**：会员、专题包、品牌定制和合规的生成服务点数。

## 核心指标

北极星指标：每周由灵感方案产生并发布的有效视频数。

辅助指标：方案展开率、提示词复制率、收藏率、7 日成片率、创作者次月留存。

## 合规原则

默认提供原创角色原型，不把受保护角色或真人肖像作为平台官方模板；用户提交具体 IP 时显示授权提醒。商业专区只使用原创、授权或公共领域素材。
