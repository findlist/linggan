# 内容分类与运营规范

## 一、内容图谱

每条灵感不是一段孤立文本，而是由以下节点组成：

```text
作品/世界观 → 角色 → 角色关系
热梗 → 语义结构 → 生命周期
名场面 → 冲突结构 → 视觉动作
场景 → 道具 → 空间约束
叙事模板 → 节奏 → 镜头模板
风格 → 光线 → 镜头语言
```

### 1. 角色 `character`

- `archetype`：原创角色原型，可直接参与创意生成。
- `reference`：动漫、电视剧、电影、游戏或真人角色，仅用于趋势关联。
- `original`：平台或创作者拥有权利的原创角色。
- `licensed`：获得明确授权的角色。

必填分类：媒介、年龄气质、能力、性格、目标、弱点、关系类型、视觉符号、版权状态。

### 2. 热梗 `meme`

记录梗的“结构”而不只记录原句：

- 梗名称和别名；
- 起源与可靠来源；
- 使用语境；
- 情绪：荒诞、吐槽、治愈、燃、悬疑；
- 可视化动作；
- 生命周期：萌芽、上升、爆发、衰退、常青；
- 平台差异和敏感风险。

### 3. 名场面 `scene`

不能只存作品名，需要抽象成可复用结构。例如“决战前互相放狠话”可抽象为：

```text
公开对峙 → 展示筹码 → 一方轻视 → 弱者反转 → 标志性收尾
```

分类包括：初遇、对决、告白、身份揭露、误会、团聚、牺牲、审判、训练、追逐、会议、比赛和日常反差。

### 4. 热门元素 `element`

动作、道具、地点、职业、食物、宠物、节日、视觉特效和声音均作为可组合元素。每个元素记录可生成性与所需镜头复杂度。

### 5. 叙事模板 `story_pattern`

首版固定维护：三段反转、误会升级、身份互换、能力错位、严肃纪录片、伪广告、倒计时挑战、循环失败、弱者觉醒和反派带娃。

## 二、标签命名规则

- 使用稳定名词，不使用“很火”“绝绝子”等主观标签。
- 中文主名称唯一，别名放入 `aliases`。
- 标签最多三级：`媒介/动漫/热血`，不继续无限嵌套。
- 角色能力与性格分开，例如“剑术”和“冷酷”不能合成一个标签。
- 所有标签有负责人、创建时间和停用状态，禁止直接删除历史标签。

## 三、每日内容工作流

### 自动阶段

1. 拉取最近 24 小时内容和热度快照；
2. 删除广告、搬运、重复和无来源内容；
3. 合并别名和同一事件；
4. 判断生命周期和增速；
5. 关联已有角色、场景和叙事模板；
6. 产生候选创意并评分；
7. 高风险内容隔离，不进入生成队列。

### 人工阶段

- 确认来源与语境是否准确；
- 判断是不是已经过时；
- 确认前三秒是否能看懂；
- 将受保护角色替换成原创原型；
- 检查生成难度和镜头连续性；
- 选择发布、排期、退回或归档。

## 四、评分模型（首版）

```text
总分 = 热度 20% + 增速 15% + 反差 15% + 可视化 15%
     + 可生成性 15% + 连载性 10% + 新颖度 10% - 风险扣分
```

风险扣分：低 0、中 15、高 40、禁止 100。不得用热度抵消禁止级风险。

## 五、数据保鲜

- 热梗：每天刷新，7 天无新信号进入衰退观察。
- 角色引用：每周更新热度，基础属性按月复核。
- 名场面：作为常青结构保留，具体作品热度每周刷新。
- 来源失效：标记证据失效，不立即删除实体。
- 90 天无人使用且无常青价值的元素进入冷库。

## 六、来源原则

只使用允许访问的公开页面、官方榜单、开放 API、RSS 和已购买的数据源。遵守 robots、服务条款和请求频率；不绕过登录、验证码、付费墙，不抓取私人账号和个人敏感信息。
