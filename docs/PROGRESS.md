## 5. 下一轮唯一首选任务

**任务：建立 TypeScript 数据契约、运行时校验与首批自动测试。**

选择理由：所有采集、图谱、生成和发布功能都依赖稳定数据结构；继续堆积 JSON 或页面会扩大返工。

验收条件：

1. 为 `character`、`scene`、`element`、`trend`、`candidate` 定义类型和运行时校验；
2. `seed-entities.json`、`taxonomy.json`、`trend-inbox.example.json` 可由统一命令验证；
3. 非法 `rights_status`、缺失来源和越界分数会校验失败；
4. 至少增加 8 个自动测试；
5. 增加 `npm test` 与 `npm run typecheck`；
6. 测试、类型检查和生产构建全部通过；
7. 更新本文件，将已完成任务移出当前首选。

## 7. 关键决策

1. 具体知名角色作为 `reference_only`，官方模板默认使用原创角色原型；
2. 自动发布不要求人工审核，但必须经过程序化安全、来源、重复和版权检查；
3. 开发采用小步可验收方式，每轮只推进一个核心目标；
4. `docs/PROGRESS.md` 是唯一当前进度真源；
5. 未经用户授权，定时 Agent 只进行本地开发和验证，不部署、不推送、不产生外部发布。
